# Interface direction

User explicitly requested an interface that does not resemble a generic AI-generated website.

Build a polished document review workspace. After the user found the initial paper/green version too boring, revise to a navy sidebar, blue action controls, stronger sans-serif hierarchy, a dotted working canvas, paper shadows and a focused review panel. Maintain clear original/overlay controls. Avoid gradient hero sections, decorative dashboard statistics, glass effects, emoji navigation and unnecessary animation.

Display model identity and whether trained weights are available. Scores are model outputs, not proof of fraud. Keep research/training details in a separate technical view. Implement the application in Phase 6 after user feedback on model phases.
